# 实验统计明细补传

本次公开768条完整轨迹、7680轮统计记录及各阶段配对明细。目录`tables`保留阶段路径；全部文件见[统计表索引](STATISTICAL_TABLES_INDEX.json)。

[768条轨迹](all_768_episodes.csv)包括主/补充预算720条、三任务迁移36条和2016后续队列12条。[7680轮记录](all_7680_rounds.csv)包含每轮Brier、选取数量、预算、风险与成本账本、累计指标及实际后端。experiment_profile和record_id用于区分重用的实验名称。其他表格保留逐划分、逐种子、逐干预比较和统计敏感性结果。

本页对应的统计表不含逐样本标签、个体选集行号或个体预测。逐样本标签、选集、预测及审计等完整证据另见[明细总目录](README.md)和[43个归档索引](DETAILS_INDEX.json)。用户已明确授权公开这些派生数据；采用tar.zst格式约159MB，每个包均已解压逐文件核验。第三方原始信用特征数据和凭据不包含在此次交付中。

数值结论仍见[清单完成总报告](../md_execution_complete_20261029/实验清单完成总报告.md)。条件预测重采样区间不代表完整训练流程的不确定性；后续年份缺标签可得时点，因此不能据此宣称严格在线验证。
