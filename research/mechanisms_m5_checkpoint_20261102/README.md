## 研究问题与固定比较

在 LendingClub 2017 与 South German Credit 上比较 OrdinaryOnly、MinRisk、D-only、Pending-aware 和明确的 ParBaLS Laplace/cost/pending 适配。每种方法保留自己的反馈历史，共享到达流、D0 表示、业务审批规则、成本和预算定义。预算为保留候选池预测风险总额的 10%，候选池最多128，参考池最多128；不是全体候选集的无限规模结论。

同状态干预固定 D/C/成本/B/学习器，只改变尚未释放的普通反馈 O：全部、空集、方向相关性高的一半、低的一半、随机一半。方向只由可见 D、Q 与 O 特征计算。它研究的是回顾性反馈可得性，不是改变实际贷款审批的因果效果。

最终主要家族固定20项：8项十轮平均Brier收益、8项同状态方向/数量交互、4项旧M4诊断规则的预测误差改善。将共同测试实体组作为条件重采样单位，并做固定家族多重性调整；20次回放不作为20个独立样本。[分析登记](source/analysis_plan.json)
