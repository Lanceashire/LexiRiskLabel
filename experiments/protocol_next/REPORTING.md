# 每轮实验报告与 GitHub 同步

用户于 2026-10-27 明确要求：每完成一轮实验，都向 GitHub 同步一次报告。

每个已完成阶段须同步本阶段代码、冻结配置、中文报告、汇总指标及验证结果。
如前阶段报告尚未同步，应在下一次同步时补齐其依赖证据。正、负结果均保留，
不得依据测试结果只发布最优配置或覆盖旧结果。

同步后读取 GitHub 分支及提交，核对远端文件树与本地拟发布文件一致；
向用户报告结果时附上远端报告和提交链接。未完成远端核验时，不称为已同步。

第三方原始数据、逐人 ID、标签、逐人选集和预测数组仅留本地 private/，
不纳入 GitHub 提交。公开汇总文件使用独立的发布清单与哈希。

该要求是每轮完成后的同步流程，不代表启动额外实验、扩大网格或建立定时任务。
