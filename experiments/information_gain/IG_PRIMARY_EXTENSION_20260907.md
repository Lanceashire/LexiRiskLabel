# Independent IG extension: primary evidence block

The primary block was fixed before inspecting predictive endpoints: rho=0.1,
four available registered or transparently reconstructed datasets, seeds
1001--1010, committee size M=20, ten rounds, and five policies. The separate
five-budget grid is subsequent robustness work and is not required to interpret
this primary block.

Primary contrasts are `LRBE-IG - QualityFirst-IG` and
`LRBE-IG - CountOnly-MinRisk`. Report cumulative feedback count, predicted
risk, realized loss, final Recall, final Brier, predicted- and realized-budget
violations, and runtime. Confidence intervals use 10,000 seed-level paired
bootstrap draws within dataset at rho=0.1. Common-state diagnostics are kept
separate from trajectory outcomes.

No historical result CSV is overwritten or spliced into this evidence block.
HMEQ, UCI, and LendingClub match the experiment registry byte hashes. PPDai is
run under an explicit actual-hash registry and labeled reconstructed-source
exploratory because historical processed byte parity is not established.
